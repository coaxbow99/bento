# 🍱 Bento Site - 

Welcome to Bento Box website made by coaxbow. This project is a simple guide for packing traditional lunch boxes but made it a bit eerie ;)

## My insipirations~🪼
I took 2 unrelated ideas and made a fusion!
* **Japanese Animation Style:** The background graphics and font choices are inspired by classic Japanese anime art style.

* **Spooky Halloween Vibe:** Since it is October, I wanted to add a dark, playful Halloween twist into the traditional bento theme.So I added recipes featuring pumpkin shaped sushi rolls and eyeball shaped nigiri to give the site its spooky aesthetic.

## Features that I added💫
* **Functional Global Navigation:** A custom styled navigation bar at the top of every page.
* **Bento Layout:** Clean content sections styled like traditional bento compartments to organize ingredients and instructions
* **High-Contrast Typography:** Custom text-shadow outlines ensuring maximum readability against a graphic background.

## What I used📓
* **HTML** - for structure 
* **CSS** - for  styling, text effects, hover.
