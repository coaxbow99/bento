# 🍱 My Bento Site - Spooky Halloween Sushi Guide

Welcome to my **Bento Box website**! This project is a simple, interactive culinary guide to packing traditional lunch boxes with a festive, creative twist.

## 🎨 Design & Inspiration
This project blends two of my favorite aesthetics:
* **Japanese Animation Style:** The background graphics and font choices are heavily inspired by classic Japanese anime art style, bringing a vibrant, cozy kitchen and street vibe to the interface.
* **Spooky Halloween Vibe:** Since it is October, I wanted to inject a dark, playful Halloween twist into the traditional bento theme. I chose custom recipes featuring spooky visuals—like pumpkin-shaped sushi rolls and eerie eyeball-shaped nigiri—to give the site a distinct "spooky season" aesthetic.

## 🛠️ Features
* **Functional Global Navigation:** A beautifully centered, custom-styled navigation bar at the top of every page for a seamless user experience.
* **Responsive Bento Layout:** Clean content sections styled like traditional bento compartments to organize ingredients and step-by-step instructions.
* **High-Contrast Typography:** Custom text-shadow outlines ensuring maximum readability against a graphic background.

## 💻 Tech Stack
* **HTML5** - Semantic structure across multiple interconnected recipe pages.
* **CSS3** - Custom styling, text effects, hover transitions, and flexible layout properties.
